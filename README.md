# Синапс — химия, физика и биология от нуля до медвуза

Интерактивная платформа без сборки и зависимостей: откройте `index.html` в браузере — и можно учиться.
Прогресс хранится локально в браузере (есть экспорт/импорт в JSON). Интерфейс и курс — на русском.

## На что ориентирован курс

Химия и биология покрывают темы кодификатора ЕГЭ (основной экзамен для поступления в медвузы РФ), с медицинскими примерами в каждом модуле.
Физика на ЕГЭ в медвуз обычно не нужна, поэтому её курс идёт до уровня, нужного для понимания физиологии и медицинской техники
(давление, кровоток, биоэлектричество, оптика глаза, УЗИ, МРТ, рентген, дозы), а не до олимпиадного. Если вы поступаете туда, где
физика — профильный экзамен, её стоит дополнить задачником.

## Запуск

```bash
xdg-open index.html            # или двойной клик
python3 -m http.server 8000    # или через локальный сервер → http://localhost:8000
```

Для публикации подходит GitHub Pages (Settings → Pages → ветка, корень репозитория).

## Структура

```
index.html               точка входа, порядок подключения скриптов
css/style.css            стили, светлая/тёмная тема, мобильная вёрстка
js/core/                 util (DOM, числа, формулы), store (прогресс, SRS, достижения), ui, chem (движок), quiz (8 типов вопросов)
js/data/                 элементы, генетический код и генетика, справочные таблицы, глоссарий
js/data/course/          уроки: chem1/2, phys1/2, bio1/2 (core.js — формат блоков)
js/gen/                  генераторы задач по предметам
js/labs/                 лаборатории
js/views/                экраны
tests/                   модульные и браузерные тесты
```

Новый урок — объект в `lessons` нужного модуля в `js/data/course/*.js` (формат блоков описан в `core.js`).
Новый генератор — вызов `defGen({...})` в `js/gen/*.js`; он сразу появится в тренажёрах, экзамене и марафоне.

## Тесты

```bash
node tests/unit.test.js                              # движок химии, генетика, генераторы (по 300 прогонов), целостность курса
NODE_PATH=$(npm root -g) node tests/smoke.test.js    # браузерный прогон всех 284 экранов (нужен playwright); MOBILE=1 — узкий экран
```

Медицинские сведения приведены для обучения и не заменяют консультацию врача.
